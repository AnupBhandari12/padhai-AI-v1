# PadhAI — Competition Pitch

## 1. Problem
Students prepare for exams using disconnected PDFs, notes, lectures, old questions and generic AI chats. They need to know not only the answer, but what to study next.

## 2. Target user
Primary: Nepal-based entrance and competitive-exam students (CEE, IOE, Loksewa, SEE, etc.).

## 3. Product
Upload study materials → PadhAI indexes them → ask grounded questions → generate practice → analyze mistakes → get the next revision action.

## 4. Differentiation
- Exam-aware workflows rather than generic document chat
- Source-grounded answers
- Weak-topic loop from quiz/mocks
- Personalized revision path
- Nepal-first exam profiles and pricing

## 5. Business
Free: limited materials + questions.
Pro: NPR 399/month equivalent.
Exam Pass: NPR 999 / 3 months.

## 6. Validation plan
Recruit 10–30 real students; track uploads, questions, quiz completion, return rate, willingness to pay and feedback. The founder admin console exposes these real database-backed signals so the presentation can show evidence instead of invented traction.

## 7. Demo script
1. Open dashboard.
2. Upload a real exam PDF.
3. Ask a grounded question.
4. Show retrieved source.
5. Generate a quiz for one topic.
6. Submit a mock test.
7. Return to dashboard and show accuracy/progress.

## 8. Roadmap
MVP → pgvector embeddings → syllabus-aware RAG → previous-question intelligence → personalization → payments → mobile app → institutional dashboard.
